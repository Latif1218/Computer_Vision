# Computer Vision

This repository contains **Computer Vision projects and practice code** built using **Python and OpenCV**.  
It is intended for learning, experimentation, and implementing fundamental to intermediate computer vision techniques.

---

## 📁 Repository Structure

```

Computer_Vision/
├── OpenCv/                  # OpenCV-based scripts and experiments
├── .gitignore               # Git ignore rules
├── LICENSE                  # Project license
├── README.md                # Project documentation
└── requirements.txt         # Python dependencies

````

---

## 🧠 What’s Inside?

### 📌 OpenCv Folder

The `OpenCv` directory contains Python scripts related to:

- Image processing
- Video processing
- Camera and video file handling
- OpenCV fundamentals
- Computer vision practice examples

These scripts are mainly focused on understanding and applying OpenCV in real-world scenarios.

---

## ⚙️ Requirements

All required Python packages are listed in `requirements.txt`.

Install dependencies using:

```bash
pip install -r requirements.txt
````

Common libraries used:

* `opencv-python`
* `numpy`

---

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Latif1218/Computer_Vision.git
```

2. Navigate to the project directory:

```bash
cd Computer_Vision
```

3. Install required dependencies:

```bash
pip install -r requirements.txt
```

4. Run any script from the `OpenCv` folder:

```bash
python script_name.py
```
